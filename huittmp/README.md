# HuittMP – Jäsenrekisteri

## Haaga-Helian Back End -ohjelmointikurssin harjoitustyö.

**Tekijä:**
Pertti Paananen

## Kuvaus
Javalla, Spring Bootilla, Thymeleafilla ja PostgreSQL-tietokannalla toteutettu jäsenrekisterin hallintasovellus.

Sovelluksessa hallitaan yhdistyksen jäsenten perustietoja sekä erilaisten maksujen ja yhdistyksen toimintaan liittyvien roolien historiaa.

## Toiminnallisuudet

- **ADMIN:** Jäsenten lisääminen, perustietojen muokkaaminen ja jäsenten poistaminen sekä rooli- ja maksuhistorian tarkastelu. Tässä sovellusversiossa rooli- ja maksutietoja ei voi muokata.

- **USER:** Omien tietojen, roolien ja maksuhistorian tarkastelu.
